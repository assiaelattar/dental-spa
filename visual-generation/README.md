# Dental Spa reference-based image work

These are specifications for a later generation pass, not generated images. Current UI uses the original clinic photos. Improve only the assets whose quality limits an actual composition. Keep an unbroken link to the original source, checksum, prompt, output version and review outcome in the asset manifest.

Before accepting an output, compare identity, architecture, equipment, brand lettering, proportions, hands and instruments against the original. Reject changed clinical details or invented features. Clinical before/after images must never use generative reconstruction. Manufacturer illustrations are not references for inventing clinic-owned equipment. Stock may illustrate a generic topic if separately labelled and licensed, but it must not represent Dr Amina or the actual clinic.

No active request to generate images is implied by these files. The user's current sequence is source photographs now, high-fidelity AI improvements later.
