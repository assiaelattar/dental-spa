## Art direction

Hero: real reception with text over a dark readability layer; Dr Amina's real portrait sits separately, never composited into another scene. Desktop uses broad context, mobile centres the reception signage and retains a separate portrait. Doctor photo uses a face-aware 4:5 crop. Botanical detail uses a rightward mobile focal point. Clinical results always show full frames, side-by-side on desktop and vertically paired on mobile. No CSS colour filter is applied to the photographs.
